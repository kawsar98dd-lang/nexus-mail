2. Installation & Setup

Because this project is entirely static (HTML/JS/CSS), installation is incredibly simple. You can host it on any standard web host, cPanel, or modern cloud platforms like Cloudflare Pages, GitHub Pages, or Netlify.

Steps to Go Live:

  1. Unzip the downloaded package.
  2. Open the Code-Canon-Project folder.
  3. Upload all files and folders (including index.html, assets, tools) to your server's public directory (e.g., public_html or htdocs).
  4. Visit your domain. The site is now live!
Note for Local Testing: Due to modern browser security (CORS), opening index.html directly from your hard drive might block some JavaScript (like dynamic headers). Please use a local server (e.g., VS Code Live Server or Spck Editor's built-in preview).

3. Folder Structure

Understanding the directory structure is crucial for making modifications.

Root/
├── index.html            // Main Homepage

    ├── img/              // Image Tools
    └── sec/              // Security Tools

4. Customization

Changing the Website Name & Logo

The header and footer are dynamically injected across all pages via JavaScript. To change the brand name or links, edit the assets/js/global.js file.

Find the loadGlobalHeader function:

// In assets/js/global.js
headerEl.innerHTML = `
    <div class="header-content">
        <a href="${root}index.html" class="header-logo">
            <i class="fa-solid fa-shield-halved"></i> Your Brand <span>Name</span>
        </a>
    </div>
`;

Changing Global Colors

All primary colors are controlled by CSS variables. Open assets/css/global.css and edit the :root variables at the top of the file.

5. Ads & Analytics Configuration

We built a centralized system so you don't have to edit 40+ individual HTML files to add your tracking or ad codes.

Google Analytics (or any tracking code)

Open assets/js/analytics-loader.js and paste your Google Analytics snippet (gtag) or other tracking scripts inside.

AdSense / Banner Ads Configuration

The script uses an intelligent ad-slot system. Open assets/js/ads-manager.js. You will find predefined ad slots like top-banner and bottom-banner. Simply replace the placeholder HTML with your Google AdSense code or custom banner images.

// Example inside ads-manager.js
const AD_UNITS = {
    'top-banner': '<!-- Your AdSense Code Here -->',
    'bottom-banner': '<!-- Your AdSense Code Here -->'
};
